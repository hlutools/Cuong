# Đèn Cuối Núi

Game 2D top-down cultivation/action RPG, offline single-player.

## Phase 0
Technical foundation only: Godot project configuration, core lifecycle/autoloads, input map and minimal startup scene.

No gameplay, art production, online/backend, multiplayer or unnecessary dependencies are included.

## Run
Open the project folder in Godot 4.x and run the project.
